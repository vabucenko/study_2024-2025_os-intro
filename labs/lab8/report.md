# Цель работы

Познакомиться с операционной системой Linux. Получить практические навыки работы с редактором vi, установленным по умолчанию практически во всех дистрибутивах.

# Задание 

- Задание 1. Создание нового файла с использованием vi

1. Создайте каталог с именем ~/work/os/lab06.

2. Перейдите во вновь созданный каталог.

3. Вызовите vi и создайте файл hello.sh 1 vi hello.sh

4. Нажмите клавишу i и вводите следующий текст.
- #!/bin/bash
- HELL=Hello
- function hello {
- LOCAL HELLO=World
- echo $HELLO
- }
- echo $HELLO
- hello

5. Нажмите клавишу Esc для перехода в командный режим после завершения ввода текста.

6. Нажмите : для перехода в режим последней строки и внизу вашего экрана появится приглашение в виде двоеточия.

7. Нажмите w (записать) и q (выйти), а затем нажмите клавишу Enter для сохранения вашего текста и завершения работы.

8. Сделайте файл исполняемым
- chmod +x hello.sh

4. Установите курсор на четвертую строку и сотрите слово LOCAL.

5. Перейдите в режим вставки и наберите следующий текст: local, нажмите Esc для возврата в командный режим.

6. Установите курсор на последней строке файла. Вставьте после неё строку, содержащую следующий текст: echo $HELLO.

7. Нажмите Esc для перехода в командный режим.

8. Удалите последнюю строку.

10. Введите символ : для перехода в режим последней строки. Запишите произведённые изменения и выйдите из vi.

# Контрольные вопросы

1. Дайте краткую характеристику режимам работы редактора vi.

- Режим командной обработки: здесь пользователь вводит команды для перемещения, редактирования, копирования и удаления текста. В этом режиме нельзя вводить обычный текст.

- Режим вставки: активируется по команде i, a, o и др., позволяет вводить текст напрямую в документ.

2. Как выйти из редактора, не сохраняя произведённые изменения?

- Из командного режима: :q! + Enter
- Альтернатива: ZQ (в командном режиме)

3. Назовите и дайте краткую характеристику командам позиционирования.

![команды и их характеристики](image/999.jpg){#fig:001 width=70%}

4. Что для редактора vi является словом?

- В vi слово — это последовательность символов, не содержащих пробелов или знаков пунктуации, если не использовать специальные параметры. Обычно слово — это последовательность символов, включающая буквы, цифры, дефисы и подчёркивания.

- Строчные (w/b): последовательность букв, цифр, _ или любой набор символов до пробела/знака пунктуации

- Прописные (W/B): только до пробелов (игнорирует пунктуацию)

5. Каким образом из любого места редактируемого файла перейти в начало (конец) файла?

- В командном режиме:
- gg — перейти в начало файла.
- G — перейти в конец файла.

6. Назовите и дайте краткую характеристику основным группам команд редактирования.

- Команды навигации: перемещения по файлу (например, h, l, j, k, G, gg, /, ?).
- Команды редактирования: вставки, удаления, копирования текста (i, a, d, c, y).
- Команды поиска и замены: /, ?, :s.
- Команды сохранения и выхода: :w, :q, :wq, :x.

7. Необходимо заполнить строку символами $. Каковы ваши действия?

- В командном режиме выполните команду:
- :s/.*/$$$$$$$$$$/

8. Как отменить некорректное действие, связанное с процессом редактирования?

- В командном режиме: u — отменяет последнее изменение.
- Для отмены нескольких — повторяйте u.

9. Назовите и дайте характеристику основным группам команд режима последней строки.

- Команды, начинающиеся с : — директивы для сохранения, выхода, поиска, замены.

- Например:
- :w — сохранить файл.
- :q — выйти.- :wq — сохранить и выйти.
- :s/старое/новое/ — заменить.

10. Как определить, не перемещая курсора, позицию, в которой заканчивается строка?

- В командном режиме нажмите: g_ — курсор перейдёт на последний не пустой символ строки.

11. Выполните анализ опций редактора vi (сколько их, как узнать их назначение и т.д.).

- В большинстве систем vi реализуется через vim, у которого есть множество опций, доступных командой: :set
- Для просмотра всех установленных опций: команда :set без параметров.
- Для изменения опции: :set имя_опции.
- Опций много: включение подсветки, отображение номеров строк, автоматическая проверка правописания и др.

12. Как определить режим работы редактора vi?

- Если можно вводить обычные текстовые символы — вы в режиме вставки.
- Если при вводе символов они интерпретируются как команды — вы в командном режиме.
- В vim подсказка отображается в статусной строке, также можно нажать Esc — после этого входите в командный режим, если не уверены.
